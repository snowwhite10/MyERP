# ADR-024：共用對話框與列表／單據頁範本的形式

- 日期：2026-10-11
- 狀態：採用
- 工作單元：WU-SYS-014

## 背景

ui-conventions 規定危險動作以 `erp-confirm` 二次確認、主檔以選擇視窗（`erp-select-dialog`，BlueWhale 4.4.1.9）選取，並有標準列表頁（`erp-list-page`）與單據頁（`erp-document-page`）範本。之前 SYS 各頁各自寫標題列、篩選列、排序轉換，角色刪除用 `nz-popconfirm`。之後十多個業務模組都要重用，需要決定形式。

需要決定：

1. 確認框／提示框用 `NzModalService.confirm()` 還是自己的內容元件；
2. 對話框服務如何取得 `NzModalService`；
3. 範本用繼承基底類別還是內容投影；
4. 輸出事件命名；
5. 測試中 nz-modal 的關閉動畫。

## 決定

1. **自己的內容元件 + `NzModalService.create()`**：`MessageDialog`（確認框／提示框）與 `SelectDialog` 以 `nzContent` 開啟，`nzFooter: null`，按鈕放在內容內。
   - 按鈕可加 `data-testid`（`erp-message-ok`、`erp-select-confirm`…），E2E 不依賴 ng-zorro 的 class；
   - 標題放在內容內而不是 `nzTitle`：nz-modal 開啟後不更新 `nzTitle`（已知問題），放在內容內可隨語言切換；
   - 結果統一成 Observable：`confirm()` → `boolean`（Esc／關閉為 `false`），`alert()` → `void`，`select()` → `T[] | null`，都只發出一次。
2. **服務自建 `NzModalService`**：`NzModalService` 不是 root 服務（由 `NzModalModule` 提供），`ErpDialogService`（root）以 `createEnvironmentInjector([NzModalService], 根環境)` 建立自己的一份。頁面與測試不必另外提供；`closeAll()` 只關閉本服務開啟的對話框。各模組一律經 `ErpDialogService`，不直接使用 NzModalService。
3. **內容投影，不用基底類別**：`erp-list-page` 提供標題列、篩選區（查詢／重設）、批次操作列、錯誤重試的版面，以 `[erpListActions]`、`[erpListFilters]`、`[erpListBatch]` 與預設插槽放入頁面自己的按鈕、欄位與 `nz-table`。分頁排序邏輯放在純函式（`table-query.ts`：`tableSort`、`sortOrderOf`、`nextTableState`），頁面仍自行持有 signals 與 API 呼叫。理由：各頁的篩選欄位、表格欄位、對話框差異很大，基底類別會變成大量可覆寫的鉤子；純函式易測，範本只管版面與 `data-testid` 一致。`erp-document-page` 同理，另有 `adjacentIds()` 與 `unsavedChangesGuard`（`HasUnsavedChanges` 介面）。
4. **輸出不用原生 DOM 事件名稱**：Angular 對元素同時註冊元件輸出與同名原生事件監聽，投影的 `<input type="search">` 冒泡的原生 `search` 事件會觸發 `(search)`。輸出改名為 `querySubmit`、`filterReset`、`retryLoad`、`selectionClear`，並有單元測試把關。
5. **測試提供 `ANIMATION_MODULE_TYPE = 'NoopAnimations'`**：jsdom 不會發出 `animationend`，nz-modal 關閉時一直等待動畫，`afterClose` 永不發出。用到 `ErpDialogService` 的元件測試加上此提供者（以及 `provideNzIcons(APP_ICONS)`，否則圖示會發出 HTTP 請求）。

## 結果

- 角色頁（8.64）改用 `erp-list-page`、`table-query` 與共用確認框，取代 popconfirm；既有測試全數保留，E2E 改為操作確認框並新增「取消不送出」。
- 其他 SYS 頁面（組織、用戶、單號規則、審批、稽核）暫不改寫，記錄於 optimization-log，之後修改這些頁面時順便遷移；新模組一律使用共用元件。
- 選擇視窗與單據頁範本目前沒有頁面使用，只有單元測試；第一個主檔／單據頁（EP-MD）採用時補 E2E。
- ui-conventions 第 5–7 節補上用法。
