# ADR-007 前端骨架實作決策（Node 執行環境、主題、i18n、圖表、測試）

- 狀態：Accepted
- 日期：2026-10-10
- 工作單元：WU-P0-010
- 相關：ADR-001（前端版本）、風險 R-016；規範見 [ui-conventions.md](../ui-conventions.md)

## 背景

WU-P0-010 建立 `src/frontend`（Angular 22.2 standalone + ng-zorro-antd 22.1.1 + AntV G2 5.4.8）。實作時有以下需要決定的事項：

- 本機系統 Node 為 22.16.0，不符合 Angular 22 `engines`（`^22.22.3 || ^24.15.0 || >=26`）。`nvm` 在無人值守 shell 中沒有輸出、無法確認切換；代理的權限設定也不允許在指令中修改 PATH 或讀取 repo 外路徑。
- ng-zorro 預編譯 CSS 的主色是 Ant Design 藍，不是馬卡龍色；暗色主題是另一份完整樣式。
- ADR-001 列出 `@ngx-translate/http-loader`，但 ui-conventions 要求語言檔按範圍（common / layout / errors / 模組 prefix）分檔並延遲載入。
- G2 以 canvas 渲染，jsdom（Vitest）沒有 canvas。

## 決定

1. **Node：repo 內可攜版 Node 24.21.0**。`tools/scripts/Invoke-Frontend.ps1` 讀根目錄 `.nvmrc`（24.21.0）；系統 Node 版本不同時，使用 `.tools/node-v24.21.0-win-x64`（不存在時從 nodejs.org 下載並以 SHASUMS256 驗證；`.tools/` 已加入 .gitignore），只在該腳本的程序內修改 PATH。所有前端指令都經這個腳本執行，例如 `& ./tools/scripts/Invoke-Frontend.ps1 npx ng build`。系統 Node 升到 24.21.0 之後，腳本直接用系統 Node。不採用 ADR-001 決定 2.4 的 Angular 21 退路。R-016 改為「已緩解」。`package.json` 加 `engines.node ^24.15.0`。
2. **主題：用 less 編譯兩份 ng-zorro bundle**。`src/styles/theme/ng-zorro-light.less`（注入）與 `ng-zorro-dark.less`（`bundleName: theme-dark`、`inject: false`）各自 import ng-zorro 的 less 原始檔，再覆寫 `@primary-color` 等變數。`ThemeService` 在暗色模式插入 `<link id="erp-theme-dark" href="theme-dark.css">`，並在 `<html>` 加上 `erp-dark` class 切換 `--erp-*` CSS 變數。新增 devDependency `less 4.9.1`（@angular/build 的 peer）。不用 `ng-zorro-antd.variable.css` 的原因：它沒有暗色版本。
3. **對比度：色值集中在 `macaron-palette.ts`，由單元測試把關**（WCAG 2.1）。亮色主色 `#3f6fa3` 配白字；暗色主色 `#6fa8dc` 配深色字（`@btn-primary-color: #141414`）。原因是暗底上的柔和主色不可能同時與暗底、白字都達到 4.5:1。圖表色盤以「與背景的對比」定稿：亮色用中等飽和度的馬卡龍色（每色 ≥ 1.8:1），暗色用淺馬卡龍色（每色 ≥ 3:1）。這與 ui-conventions 原本「暗色降低亮度」的寫法相反，以對比檢查為準。`styles.scss`、兩份 less 與 `macaron-palette.ts` 的色值必須同步修改。
4. **i18n：自訂 `ScopedTranslateLoader`，不用 http-loader**（已從 package.json 移除）。`public/i18n/{lang}/{scope}.json` 的內容放在 `{scope}` 節點下，所以 key 一律以範圍開頭。啟動時載入 common / layout / errors；模組路由加 `canActivate: [i18nScopeGuard('<prefix>')]` 延遲載入模組範圍，切換語言時自動補載已登記的範圍。單一檔案載入失敗時以空物件代替（畫面顯示 key），不阻擋整個語言。三語 key 是否一致由 `i18n-keys.spec.ts` 檢查。新增範圍時要在 `src/testing/i18n-fixtures.ts` 登記三種語言。
5. **圖表：G2 規格用純函式產生，渲染另外封裝**。`chart-specs.ts` 產生 G2 spec（主題、色盤、千分位、系列翻譯、圓餅圖超過 7 類時合併「其他」、迷你趨勢），可直接單元測試。`erp-g2-chart` 透過 `CHART_FACTORY` token 建立圖表，測試時改用 `FakeChart`。`erp-line-chart` / `erp-column-chart` / `erp-pie-chart` / `erp-kpi-card` 經 `injectChartContext()` 讀取主題與語言 signal，主題或語言改變時重新渲染同一個圖表實例。G2 只在 lazy chunk（首頁）載入，不進入初始 bundle。
6. **其他**：zoneless（Angular 22 預設）、`strict` + `strictTemplates`；元件 selector 前綴 `erp-`；檔名採 Angular 新風格（`main-layout.ts`、頁面 `*.page.ts`）。單元測試用 Vitest 5（CLI 預設），覆蓋率用 `@vitest/coverage-v8`，門檻設在 `angular.json`（statements / lines / functions 80%、branches 70%）。初始 bundle 預算放寬到 warning 2 MB / error 3 MB（完整 ng-zorro CSS 約 560 KB）。G2 相依的 CommonJS 套件列入 `allowedCommonJsDependencies`。
7. **API 標頭**：`apiHeadersInterceptor` 只對 `/api/` 請求加上 `Accept-Language`（目前語言）與 `X-Company-Id`（目前公司，可被明確指定的標頭覆蓋）；語言檔等靜態資源不加。

## 後果

- 第一次執行前端指令會下載約 38 MB 的 Node 壓縮檔，需要網路連線；CI（WU-P0-011）用 `actions/setup-node` 讀 `.nvmrc`，不使用這個腳本。
- ng-zorro 改用 less 編譯，建置時間增加幾秒；升級 ng-zorro 時要確認 less 變數名稱沒有改變。
- 暗色模式的主要按鈕是深色文字，與 Ant Design 預設（白字）不同，是刻意的選擇。
