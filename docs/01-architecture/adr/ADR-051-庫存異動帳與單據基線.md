# ADR-051：庫存異動帳與單據基線

- 日期：2026-10-13
- 狀態：Accepted
- 工作單元：WU-INV-001

## 情境

INV 將接收本模組與 PUR、SD、PP 的庫存異動。數量、審批、儲位及估值規則若在各單據自行決定，將無法保證一致的現存量與過帳防重放。

## 決策

1. 每筆異動屬一家公司、物料、倉庫及可選儲位；以不可改寫的 `inv_stock_movement` 保存來源單據類型、ID、行號、方向、基本單位數量、業務日期、單位成本及過帳時間。數量使用 `decimal(19,6)`，正數輸入、方向單獨表示；單據輸入數量先透過 MD 換算至物料基本單位，超過六位小數拒絕，不默默捨入。金額使用 `decimal(19,4)`；估值細節於 WU-INV-014 確定。
2. 同公司、來源類型、來源 ID、行號、方向設唯一鍵，來源重送回既有結果；同一來源內容不一致時拒絕。所有出入庫透過 INV 過帳服務，在一個交易內檢查並追加異動，結存由異動帳推導，可另有可重建的讀取快取，但不得直接 UPDATE 彙總數量。
3. 預設禁止負庫存。出庫在同公司物料／倉庫／儲位粒度序列化並檢查可用量，並行出庫不得超賣；已核准但庫存不足時過帳失敗，單據維持可重試的核准狀態。允許負庫存若未來有確定業務需求，另立 ADR 和權限，不以單據參數繞過。
4. 倉庫未啟用儲位管理時，異動儲位為 null；啟用時必填且必須屬同公司、同倉庫且啟用。倉庫管理設定有交易後不得改變；詳細驗證由 WU-INV-003 實作。物料、倉庫、儲位引用驗證及 MD 刪除互斥按 ADR-049／050，在 WU-INV-002 完成。
5. 單據狀態為 `Draft → PendingApproval → Approved → Posted`，送審拒絕為 `Rejected`，草稿可作廢為 `Voided`。被拒單要修改時建立新草稿修訂版；已過帳單據不可修改或刪除，只能以新反向單據沖回。最終核准經 SYS 審批服務，核准回調只改核准狀態；過帳與追加異動在同一交易，重試安全。無審批步驟時仍經 SYS 自動核准。
6. INV 不讀寫 MD 或 SYS 的資料表；使用 Contracts/Application 查詢與審批、單號介面。每個庫存查詢與寫入均要求目前公司，資料模型繼承共用公司篩選並設同公司外鍵。模組骨架不開放空 API；第一張表與 SQL 公司隔離整合測試在 WU-INV-003 加入。
7. WU-INV-014 才確定成本法與 FI 過帳契約。過帳時保存成本資料快照，後續估值計算不得回寫已過帳異動；匯率與貨幣精度沿用 MD 契約。

## 後果

WU-INV-002 完成引用安全；WU-INV-003 建立 migration、過帳服務和並發整合測試。WU-INV-004 起各業務單據透過相同狀態機與過帳服務。建立表前沒有可測的 SQL 隔離，WU-INV-001 以領域狀態守衛及架構測試把關。
