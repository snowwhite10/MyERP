# ADR-037 — 幣別與匯率模型

- 日期：2026-10-12
- 狀態：Accepted
- 工作單元：WU-MD-016（幣別與匯率）

## 背景

MASTER_PROMPT 第 6.3、6.6 節要求外幣交易同時保存 `currency_code`、`exchange_rate`、原幣與本位幣金額，金額按幣別小數位在明細行以 `Money.Round` 取整；示範資料有本位幣 TWD 與 HKD 兩間公司及 USD、CNY、JPY 外幣交易。BlueWhale 沒有幣別或匯率功能（reference-notes 無對照，舊系統只有單一幣別），`sys_company` 也沒有本位幣欄位（ADR-023 把 TWD／HKD 暫記在種子定義）。需要決定：

1. 本位幣記在哪裡。
2. 幣別的欄位、小數位與 `CurrencyPrecision` 的關係。
3. 匯率的方向、精度、來源與有效期間規則。
4. 給 FI／PUR／SD 的查詢契約。

## 決定

1. **本位幣是公司的 MD 幣別旗標。** `md_currency`（REQ_DS43.117）按公司保存，`is_base` 標示本位幣；篩選唯一索引 `(company_id) WHERE is_base = 1 AND is_deleted = 0` 保證每間公司最多一個。不在 `sys_company` 加欄位，因為 SYS 不應依賴 MD 的幣別資料，而其他模組都經 MD 契約取得本位幣。
   - 第一個本位幣可在建立或修改幣別時設定；把另一個幣別設為本位幣時，原本位幣自動取消。
   - 公司已有任何（未刪除）匯率後，本位幣不可再更換（409 `MD.CURRENCY.BASE_LOCKED`），因為既有匯率都是對舊本位幣的報價。FI 開始後，已有過帳交易亦應鎖定，屆時由 FI 經契約補上檢查。
   - 不可直接取消本位幣旗標（422 `MD.CURRENCY.BASE_REQUIRED`）；本位幣不可停用（422 `MD.CURRENCY.BASE_INACTIVE`）或刪除（409 `MD.CURRENCY.IS_BASE`）。
2. **幣別欄位。** 代碼為 ISO 4217 三個英文字母（大寫，`CHAR(3)`，MASTER_PROMPT 6.3），建立後不可修改，軟刪除後仍保留；名稱（200）、符號（可空，10）、金額小數位 `decimal_places`（0–4；金額欄位是 `DECIMAL(19,4)`，超過 4 位無法保存）。幣別沿用 `MasterCategoryService`。
   - MD 契約提供 `GetPrecisionAsync`，以 `CurrencyPrecision.Default` 為基礎套用公司幣別的小數位，業務模組把它傳給 `Money.Round(value, currency, precision)`；未在主檔的幣別仍用預設（TWD／JPY 0 位，其他 2 位）。
3. **匯率。** `md_exchange_rate`（REQ_DS43.118）：幣別、生效日 `effective_from`、到期日 `effective_to`（可空表示持續有效，含當日）、匯率 `DECIMAL(19,8)`（MASTER_PROMPT 6.3）。
   - **方向**：1 外幣 = `rate` 本位幣（例如 USD → TWD 32.15）。本位幣本身不可設匯率（422 `MD.EXCHANGE_RATE.BASE_CURRENCY`），查詢本位幣固定回 1。
   - **來源**：本期只有人手維護；日後若接外部匯率來源，以排程寫入同一張表。不區分買入／賣出／中間價，一律視為記帳匯率。
   - **期間不重疊**：同一幣別未刪除的匯率期間不可重疊（409 `MD.EXCHANGE_RATE.OVERLAP`），在公司級 applock `md_currency:{companyId}` 內檢查；資料庫另有 `(company_id, currency_id, effective_from)` 篩選唯一索引與 `rate > 0`、`effective_to >= effective_from` CHECK。
   - 公司沒有本位幣時不可新增匯率（422 `MD.EXCHANGE_RATE.NO_BASE_CURRENCY`）；只能為啟用的外幣新增匯率（422 `MD.EXCHANGE_RATE.CURRENCY_INACTIVE`）。修改可改期間與匯率，不可改幣別。刪除為軟刪除。
   - 已存單據自己保存成交匯率與本位幣金額（MASTER_PROMPT 6.6），所以修改或刪除匯率不影響已存單據；匯率表不加 `is_active`。
   - 有匯率的幣別不可刪除（409 `MD.CURRENCY.IN_USE`）。
4. **契約。** `MyERP.Modules.MasterData.Contracts.ICurrencyLookup`：`GetBaseCurrencyAsync`（無則 null）、`FindCurrencyAsync(code)`（含停用，不存在 null）、`GetRateAsync(code, date)`（本位幣回 1；幣別不存在 404 `MD.CURRENCY.NOT_FOUND`；沒有本位幣或沒有涵蓋該日的匯率 422 `MD.EXCHANGE_RATE.NO_BASE_CURRENCY`／`MD.EXCHANGE_RATE.NOT_FOUND`）、`GetPrecisionAsync`。停用幣別仍可查匯率（歷史單據），新單據是否接受停用幣別由呼叫端以 `IsActive` 判斷。
5. **權限與 API。** `MD.CURRENCY.VIEW／CREATE／EDIT／DELETE`。匯率屬於幣別主檔：查看需 VIEW，新增、修改、刪除需 EDIT（同 ADR-035、ADR-036）。API：`/api/v1/md/currencies`、`/api/v1/md/currencies/{currencyId}/rates`、`GET /api/v1/md/exchange-rates/lookup?currencyCode=&date=`。

## 影響

- 幣別與匯率是 BlueWhale 沒有的追加子功能（ADR-002）：REQ_F4118.35（Currency）、REQ_F4118.36（Exchange Rate），介面追加 8.79–8.82。
- 示範公司的本位幣（TWD／HKD）待 MD 種子資料建立時寫入（WU-MD-022 收尾或 FI 種子）。
- SD／PUR／FI 取匯率一律經 `ICurrencyLookup`，不得讀 `md_currency`／`md_exchange_rate`。
