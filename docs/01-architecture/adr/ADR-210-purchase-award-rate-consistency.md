# ADR-210: 採購決標轉單的匯率快照一致性

Date: 2026-11-27T10:12:25+08:00

Status: Accepted

## Context

WU-PUR-005e4 的多行 CONVERT 只要求同一供應商與原幣。決標行可在不同日期保存不同匯率，而現有採購單表頭只有一個 `exchange_rate`。採購發票的 FI 來源會使用這個表頭快照換算；任選其中一行的匯率會使其他行與應付金額不一致。

## Decision

同批決標行還須有相同本位幣與相同已保存匯率。不同原幣、本位幣或匯率時整批回 422，指出匯率不一致，不建立單號或訂單。行價、稅與本位幣金額仍從各決標快照複製，不按轉單日 MD 主檔重估。將來若業務需要混合匯率，先擴充發票與 FI 來源契約為逐行匯率，再放寬此限制。

## Consequences

既有單一表頭匯率可與轉單行逐一一致；跨日期同幣別但不同匯率的決標須分單轉換。此限制加入 REQ_F4114.6.3 驗收與 PUR-RFQ-065。
