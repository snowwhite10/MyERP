# ADR-067 安全庫存門檻與低量判定

- 日期：2026-10-16T10:39:43+08:00
- 狀態：接受
- 工作單元：WU-INV-013d

## 背景

INV 的現存量由不可變異動帳即時計算；MD 擁有物料與倉庫。安全庫存須能提醒補貨，但不可在查詢時改動庫存，也不可跨模組直接讀 MD 表。現存量可按儲位分組，補貨決策則以整個倉庫為單位。

## 決定

1. `inv_safety_stock_threshold` 每公司、物料、倉庫最多一筆有效門檻，數量為基本單位 `decimal(19,6)`，須大於零；未設定不產生低量提醒。停用門檻以軟刪除保存審計，再設定同鍵時恢復同一筆並遞增版本，不建立第二筆。
2. 目前可用量採該物料在倉庫全部儲位的已過帳現存量之和，不扣未核准單據，不按批序號再加總一次。`onHand < threshold` 才低量；相等不低量；零結存仍須列出。`shortage = threshold - onHand`，只作提示，不自動建立採購單或異動。
3. 門檻表由 INV 擁有；物料及倉庫只存 MD ID，不建跨模組 FK/navigation。寫入時透過 MD Contracts 驗證同公司且啟用，使用既有引用共享鎖至提交；列表顯示代碼名稱經 MD 唯讀契約取得，已停用的歷史引用仍可顯示。
4. 列表只從「已設定門檻」出發，再以目前公司異動帳聚合現存量；先對門檻做穩定分頁，低量篩選則必須在分頁前完成，避免頁數與總筆數錯誤。所有回應標記查詢時刻；庫存隨後變動時使用者重新整理。UI 文字為「建議補足」而非自動採購承諾。
5. 權限分為 `INV.SAFETY_STOCK.VIEW` 與 `INV.SAFETY_STOCK.EDIT`。讀取與編輯都受目前公司限制；同公司不同資料範圍的限制沿用 INV 查詢政策。並發編輯依版本回 409；重複鍵建立回 409，已軟刪鍵允許恢復。

## 影響

需一張 INV 門檻表與查詢索引；沒有新的結存彙總表，也不修改異動帳。後續若要計入預留量或採購在途量，須另定來源契約與需求版本，不能默默改變此低量定義。
