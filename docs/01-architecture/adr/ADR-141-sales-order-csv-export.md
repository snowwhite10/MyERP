# ADR-141: Sales order CSV export is server-generated, line-level and language-following

Date: 2026-11-20. Status: Accepted (WU-SD-003c5a).

## Context

REQ_F4112.2.1 requires a separate `SAL.ORDER.EXPORT` permission before order export is offered. ui-conventions §10 says exports are generated by the backend and MASTER_PROMPT §9.1 requires export headers and enum text to follow the user's language via `Accept-Language`. Existing INV CSV exports stream from the server but use fixed English headers; PUR builds CSV in the browser. Excel/PDF print infrastructure (letterhead, seal, print settings) does not exist yet.

## Decision

- `GET /api/v1/sal/orders/export` accepts the same filters as the list (`keyword`, `from`, `to`, `status` by name, `customerId`, single `sort`) and ignores paging. Validation is shared with the list, so a reversed date range or numeric status is 400.
- The route requires `SAL.ORDER.EXPORT` only, and rows use the EXPORT action's SYS data scope (not VIEW's). Soft-deleted orders are excluded by the global filter.
- One CSV row per saved order line, carrying the saved header snapshot (number, date, status, customer, currency, rate, remark) and line amounts. Delivery balance and approval history are not exported in this version; they are advisory projections owned by View.
- Header names and status text are zh-Hant / zh-Hans / en, chosen by the shared `ErpProblemDetailsFactory.ResolveLanguage` (unknown → zh-Hant); status wording matches the screen status tags. Dates are ISO `yyyy-MM-dd` and decimals use invariant culture at their saved scale in every language, so the file re-reads exactly.
- UTF-8 with BOM, CRLF row ends, RFC 4180 quoting. Text cells starting (after spaces) with `= + - @`, tab or CR get a leading apostrophe against spreadsheet formula injection.
- Count and rows are read in one SNAPSHOT transaction. More than 10,000 lines → 422 `SAL.ORDER.EXPORT_LIMIT` before any byte is written. Response header `X-Export-Row-Count` gives the written line count; 0 means header only, which the client must present as a warning, not success. `Content-Language` echoes the chosen language.
- CSV is the first export format. Excel and server PDF print are deferred until shared print infrastructure exists; the print action stays hidden until then.

## Consequences

The Angular View page (WU-SD-003c5b) only needs to send filters and the current language, read the row count and save the blob. `X-Export-Row-Count` is not yet in the CORS exposed-header list; the dev proxy is same-origin, and 003c5b must add it before relying on it across origins. Excel/PDF and print remain open under REQ_F4112.2.1 and will need their own ADR.
