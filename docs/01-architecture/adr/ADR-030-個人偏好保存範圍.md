# ADR-030 個人偏好保存範圍

- 日期：2026-10-11
- 狀態：已採用
- 範圍：WU-SYS-011b、REQ_F4111.1.5

## 背景

前端在基礎階段已有 `LanguageService`、`ThemeService` 與 `PreferenceStorage`，可即時套用三語與亮／暗／跟隨系統主題，並在瀏覽器重新整理後保留。WU-SYS-011b 要提供個人設定頁並保存偏好，但目前沒有個人資料 API；本工作單元的需求沒有要求跨裝置同步。

## 決定

個人設定頁直接使用現有兩個服務：語言存 `myerp.lang`、主題存 `myerp.theme`。頂列快捷選單與個人設定頁讀寫同一份值。保存範圍明確標示為目前瀏覽器；localStorage 不可用時仍可在當前頁面使用記憶體退路。此範圍不新增資料庫表或 API。

## 結果與限制

同一瀏覽器的不同登入帳號共用語言與主題偏好，跨裝置不會同步。日後若需要按帳號保存，應先定義 `sys_user` 偏好欄位或獨立設定表、版本與 API，再將本機值作首次載入備援。現在沒有假稱伺服器已保存；介面明示「儲存在此瀏覽器」。
