# ADR-004 測試平台（Microsoft.Testing.Platform）與後端建置設定

- 狀態：Accepted
- 日期：2026-10-10
- 工作單元：WU-P0-006
- 相關：ADR-001 決定 1.2、1.5；ADR-003 決定 5

## 背景

WU-P0-006 建立後端骨架時實測：

1. xunit.v3 4.0.2 測試專案以 Microsoft.Testing.Platform（MTP）執行。.NET 10 SDK 的 `dotnet test` 預設仍走 VSTest，對 MTP 專案直接報錯：「Testing with VSTest target is no longer supported by Microsoft.Testing.Platform on .NET 10 SDK and later」。
2. 測試專案位於 repo 根目錄 `tests/`，不在 `src/backend/` 之下，不會自動套用 `src/backend/Directory.Build.props` 與 `Directory.Packages.props`（ADR-001 決定 1.2 指定集中版本檔放 `src/backend/`）。
3. VM 的使用者層級 NuGet 設定含多個需驗證的私有來源，可能令還原變慢或失敗，CI 環境亦不應依賴。
4. `AnalysisLevel=latest-recommended` + `TreatWarningsAsErrors` 下，CA1716（命名空間與 VB 保留字衝突）會因架構既定名稱 `MyERP.Shared`、`MyERP.Modules.System` 報錯。

## 決定

1. **保留 xunit.v3 4.0.2**（不採用 ADR-001 決定 1.5 的退路），於 `global.json` 加入 `"test": { "runner": "Microsoft.Testing.Platform" }`，改用 .NET 10 的新 `dotnet test` 模式。測試指令改為：
   - 全部：`dotnet test --solution src/backend/MyERP.sln --no-build`
   - 單一專案：`dotnet test --project tests/backend.unit/MyERP.ArchitectureTests/MyERP.ArchitectureTests.csproj`
   - 篩選：`--filter-method "*Domain*"`（MTP 參數，不再使用 VSTest 的 `--filter`）
   CLAUDE.md / AGENTS.md 同步更新。`xunit.runner.visualstudio` 仍保留，供 IDE 測試總管使用。
2. **集中設定單一來源**：版本與共同屬性只寫在 `src/backend/Directory.Build.props`、`src/backend/Directory.Packages.props`；`tests/Directory.Build.props`、`tests/Directory.Packages.props` 以 `<Import>` 匯入，前者另加測試共同屬性（`OutputType=Exe`、`IsTestProject`）與共同測試套件（xunit.v3、FluentAssertions、Moq、coverlet 等）。不得在 tests 端另寫版本號。
3. **repo 根目錄 `nuget.config`**：`<clear />` 後只加入 nuget.org，令本機與 CI 還原結果一致。
4. **全域停用 CA1716**（附註釋說明），其餘 `latest-recommended` 規則維持錯誤等級；測試專案另停用 CA1707（測試方法名稱使用底線）。
5. 架構測試的實作方式：不引入 NetArchTest（ADR-003 決定 2），以反射 + 最小 IL 讀取器（`tests/backend.unit/MyERP.ArchitectureTests/Infrastructure/IlReader.cs`）檢查方法本體的呼叫，涵蓋 lambda / async 產生的巢狀型別；檢查邏輯另有自我測試（刻意違規的 Fixtures），確保規則不會「空集合通過」。

## 考慮過的方案

| 方案 | 不採用原因 |
|---|---|
| 退回 xunit 2.9.3 + VSTest | 需降版且 xunit 2 已停止新功能；MTP 為 .NET 10 推薦方向，實測可行 |
| 專案內設 `TestingPlatformDotnetTestSupport=false` 強走 VSTest | 與 .NET 10 新模式背道而馳，日後 SDK 升級可能失效 |
| 把 Directory.*.props 移到 repo 根目錄 | 偏離 ADR-001 已寫明的位置（ADR 不得改寫）；以 Import 達到同樣效果 |

## 影響

- WU-P0-011 CI：GitHub Actions 須使用同一指令（`dotnet test --solution ...`），`actions/setup-dotnet` 讀取 `global.json`。
- 之後新增的測試專案放在 `tests/` 下即自動套用共同設定，專案檔只需寫 ProjectReference 與額外套件。
