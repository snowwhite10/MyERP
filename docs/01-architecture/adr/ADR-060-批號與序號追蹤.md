# ADR-060：批號與序號追蹤

- 日期：2026-10-13T20:31:28+08:00
- 狀態：Accepted
- 工作單元：WU-INV-008（拆為 008a／008b／008c）

## 背景

WU-INV-008 要求物料可按批號或序號追蹤：入庫時採集、出庫時核對可用批序號、序號不可重複出庫，並能追溯。MD 物料主檔原本沒有追蹤設定；INV 不得讀 `md_item`（ADR-049、ADR-052），只能經 MD Contracts。整個單元同時改 MD 主檔與頁面、新增 INV 三張表、修改三種過帳來源、追溯 API 及三語頁，遠超單輪 90 分鐘上限。

## 決策

1. **拆分**：
   - 008a：MD 物料 `tracking_mode`（`None`／`Lot`／`Serial`）、API、物料頁欄位、INV 取得追蹤方式的契約；
   - 008b：INV 批號／序號資料表、過帳契約擴充、其他入庫／期初庫存採集、其他出庫核對、追溯查詢 API、真實 SQL／HTTP 測試；
   - 008c：其他入庫／出庫／期初頁的批號／序號輸入、追溯查詢頁、Vitest 與 Playwright。
   三段完成才關閉 008。調撥、盤點、組裝、拆卸（009–012）及 PUR／SD 過帳契約（015）沿用 008b 的過帳契約。
2. **追蹤方式屬 MD**：`md_item.tracking_mode` varchar(30)，預設 `None`，CHECK 限三值。只有沒有任何使用方 `IItemUsage` 回報已使用時才可改變；否則 409 `MD.ITEM.TRACKING_MODE_LOCKED`，須另建物料。這避免同一物料一部分庫存沒有批號、另一部分要求批號而無法核對。匯入建立的物料一律 `None`。
3. **互斥**：改變追蹤方式時持有 `md_item` 公司排他鎖到提交；INV 寫入經 `IInventoryReferenceGuard` 在同名共享鎖內驗證並取得 `InventoryReferenceCodes.TrackingMode`（008a 已加入）。過帳在保存引用（`inv_reference`）前都持有共享鎖，因此不會出現「MD 剛確認未使用並改成 Lot，INV 卻用舊的 None 寫入第一筆」的競態。
4. **批號**（008b，`inv_lot`，REQ_DS43.142）：公司 + 物料 + 批號唯一；批號 1–50 字元，去除前後空白，大小寫不敏感（依資料庫定序）；可選生產日期與有效期限（有效期限不早於生產日期），首次入庫時建立，之後同批號入庫必須沿用相同日期，否則 422 `INV.LOT.ATTRIBUTE_MISMATCH`。批號本身不存數量。
5. **序號**（008b，`inv_serial`，REQ_DS43.143）：公司 + 物料 + 序號唯一（不同物料可有相同序號，因序號由各製造商編碼）；序號 1–100 字元。序號追蹤物料的數量必須為整數，且每個序號一個基本單位。不存可改寫的在庫狀態欄。
6. **異動明細**（008b，`inv_stock_movement_tracking`，REQ_DS43.144）：每筆異動帳對應多行（批號 ID 或序號 ID 擇一、數量），明細數量合計必須等於異動數量；與 `inv_stock_movement` 一樣只增不改（trigger 拒絕 UPDATE／DELETE）。批號與序號的結存一律由此表配合異動方向即時加總，不另存彙總。
7. **過帳契約**：`InventoryPostingLine` 增加可選 `Tracking`（批號或序號、數量）。追蹤方式為 `None` 的物料帶批序號回 400；`Lot`／`Serial` 物料缺少或合計不符回 422 `INV.TRACKING.REQUIRED`。入庫：序號在公司內該物料仍有結存（任何倉庫）時 409 `INV.SERIAL.IN_STOCK`；出庫：批號或序號在該結存鍵（物料 + 倉庫 + 儲位）不足時 422 `INV.LOT.INSUFFICIENT`／`INV.SERIAL.NOT_AVAILABLE`。出庫沿用 ADR-053 的結存鍵排他鎖；序號入庫另取 `inv_serial:{company}:{item}` 排他鎖，序列化同物料序號的入庫檢查。冪等重放比較的快照包含批序號明細。
8. **單據**：其他入庫、其他出庫、期初庫存明細各加批序號子表 `*_line_tracking`（不用 JSON 欄位，因為追溯查詢需要索引），於核准／提交時轉成過帳契約的 `Tracking`；草稿可先不填，送審前檢查。
9. **追溯**：008b 提供 `GET /api/v1/inv/tracking/lots|serials`（權限 `INV.TRACKING.VIEW`）查批號／序號的現存位置與完整異動歷史（來源類型、來源 ID、日期、方向、數量）。大量資料的進出存與追溯報表留 WU-INV-017。

## 影響

- MD `md_item` 新增欄位（migration `MasterData_ItemTrackingMode`），既有物料為 `None`，行為不變。
- 既有 `IItemUsage` 契約不變；INV 的 `InventoryReferenceService` 已在共享鎖內記錄引用，008b 只需把 `TrackingMode` 一併傳回給過帳服務。
- 先進先出、有效期限預警與自動選批不在 008 範圍；自動選批若有需要，列入創意擴充或 WU-INV-014／017 評估。
