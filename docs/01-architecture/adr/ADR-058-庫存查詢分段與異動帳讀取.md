# ADR-058 庫存查詢分段與異動帳讀取

- 日期：2026-10-13T19:16:30+08:00
- 狀態：Accepted
- 工作單元：WU-INV-006

## 決策

WU-INV-006 拆成 006a（結存／異動明細 API、SQL 驗收）與 006b（三語頁、列印、供 Excel 開啟的 CSV 匯出及瀏覽器驗收）。兩段都完成後才將 006 標為 DONE。

結存由 `inv_stock_movement` 的方向與數量按目前公司、物料、倉庫、儲位即時計算，不建可修改的彙總表。異動明細只讀本模組異動帳，依業務日期與 ID 穩定排序；回應保留 MD ID 與已保存的代碼快照，前端可透過 MD API 載入名稱，不在 INV 後端跨模組查表。結存使用 `INV.INVENTORY.VIEW`，異動明細使用 `INV.MOVEMENT.VIEW`。兩個列表均在 SQL 端篩選及分頁。

## 理由

API 的分頁、公司隔離及異動追溯可獨立以真實 SQL 驗證；前端匯出需逐頁載入並確認三語、權限與試算表安全，合併成一輪超過 90 分鐘。CSV 格式沿用 ADR-056，原生 XLSX 留 WU-INV-017 評估。
