# ADR-057：其他出庫審批與估算成本

- 日期：2026-10-13
- 狀態：Accepted
- 工作單元：WU-INV-005a

## 背景

WU-INV-005 同時包含 SQL 過帳、SYS 審批、三語頁與 E2E，超過單輪 90 分鐘上限。現有 `StockPostingService` 只容許出庫異動的 `UnitCost = null`，成本由後續 WU-INV-014 估值；其他出庫仍可能需要估算金額決定審批級別。

## 決策

拆為 005a 後端及 005b 前端。005a 沿用其他入庫草稿、公司隔離、單號、版本、SYS 審批同交易模式，出庫方向改為 `Out`。單據明細的 `unit_cost`／`amount` 僅是審批估算快照，核准時以成本 null 寫入不可改寫的異動帳。庫存可用量在過帳交易內依結存鍵鎖驗證；不足時審批結果、單據狀態與異動全部回滾。005b 顯示「估算單價」，避免使用者將其誤認為已估值成本。

## 影響

出庫單列表和列印顯示的金額是估算，不可作為財務存貨成本或會計過帳依據。估值法及已過帳出庫成本顯示留 WU-INV-014；後續若需要把成本回寫到異動帳，須另寫 ADR，遵守異動帳不可改寫規則。
