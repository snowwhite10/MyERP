# ADR-056：其他入庫列印與匯出

- 日期：2026-10-13T18:18:09+08:00
- 狀態：Accepted
- 工作單元：WU-INV-004b

## 情境

其他入庫 API 已提供分頁列表與單據詳情，沒有專門的列印或匯出端點。列表需要遵從現有篩選及公司權限；單據列印需要顯示 MD 主檔名稱。

## 決策

1. 列印先取單據詳情，再經 MD API 解析物料、倉庫、儲位名稱，以獨立的列印樣式交給瀏覽器列印。列印只需其他入庫查看權限，沒有修改資料的行為。
2. 匯出依目前篩選逐頁取完全部列表資料，輸出帶 UTF-8 BOM 的 CSV；Excel 可直接開啟，檔名 `other-receipts.csv`。匯出包含單號、日期、狀態、行數、總數量、總金額與備註。引號跳脫，對可能成為試算表公式的欄位加前置單引號。沿用列表 API 的公司隔離及查看權限。
3. 本輪不另建資料庫匯出任務；大量資料的背景匯出與真正 `.xlsx` 檔案列入後續庫存報表工作單元 WU-INV-017 評估。
4. 數量與單價由表單以十進位文字傳給 API，僅在本端點的兩個 decimal 輸入欄位允許 JSON 數字字串。這避免 JavaScript `number` 在 19 位精度內先行捨入；後端仍以 decimal 驗證六位小數及資料庫範圍。

## 後果

CSV 是供 Excel 開啟的格式，與原生 `.xlsx` 不同。逐頁載入適合一般入庫清單；大量資料時需 WU-INV-017 的伺服器端方案。
