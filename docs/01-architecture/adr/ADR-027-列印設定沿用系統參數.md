# ADR-027：列印設定沿用系統參數

- 日期：2026-10-11
- 狀態：採用（WU-SYS-010c）

## 背景

BlueWhale 的 Print Settings（4.1.1.8.18，介面 4.4.1.8.56）存放在 `SystemSet` 的固定欄位：列印抬頭（公司名稱、地址、電話、傳真、郵遞區號）、採購單與銷售出貨單的頁尾備註、是否列印 Logo、是否列印印章。每間分店一列，沒有長度檢查與權限檢查。

ADR-026 已建立按公司保存、由模組宣告的參數機制，並說明列印抬頭與備註留給本工作單元。需要決定用參數還是另開專表，以及其他模組列印時怎樣讀取。

## 決定

1. **用參數，不開專表**：SYS 在 `print` 分組宣告 9 個參數，按公司保存（ADR-026 第 2 點）：
   - 抬頭（Text）：`SYS.PRINT_COMPANY_NAME`（100）、`SYS.PRINT_ADDRESS`（200）、`SYS.PRINT_POSTAL_CODE`（10）、`SYS.PRINT_PHONE`（30）、`SYS.PRINT_FAX`（30），預設空白；
   - 頁尾備註（Text 500）：`SYS.PRINT_PURCHASE_ORDER_FOOTER`、`SYS.PRINT_SALES_DELIVERY_FOOTER`，預設空白；
   - `SYS.PRINT_SHOW_LOGO`、`SYS.PRINT_SHOW_STAMP`（Boolean，預設 `false`；圖片在 WU-SYS-010d 上傳）。
   欄位都是單一公司一個值，沒有明細或關聯，參數表足夠；保存、版本、稽核與批次驗證全部沿用，不需要 migration。頁尾備註雖然由 PUR／SD 使用，但屬於整份列印版面設定，與抬頭一起由 SYS 宣告，避免 PUR／SD 尚未開發時沒有地方設定。
2. **抬頭公司名稱空白時用公司主檔名稱**：大部分公司的列印名稱與主檔名稱相同，不必重複輸入。
3. **其他模組經 Contracts 讀取**：`MyERP.Modules.System.Contracts` 提供 `IPrintSettingsReader` 與 `PrintSettings` 記錄，SYS 以 `ISystemParameters` 與公司主檔實作。列印單據的模組只引用 Contracts，不知道參數鍵，也不讀 `sys_company`。
4. **權限沿用 `SYS.PARAMETER.VIEW`／`EDIT`**：列印設定經同一個參數 API 保存，若另設權限，API 要按分組判斷權限，複雜度不值得。
5. **畫面**：`/sys/print-settings`（介面 8.56）重用參數頁元件，只顯示 `print` 分組，並加抬頭預覽；`/sys/parameters` 不再重複顯示 `print` 分組。長度超過 100 的文字參數改用多行輸入框（兩個頁面共用）。

## 後果

- 新增列印欄位只需宣告參數與三語名稱。
- 列印設定與其他參數共用權限；若日後需要分開授權，可再加分組層級的權限檢查。
- `print` 分組的參數在 `/sys/parameters` 隱藏，參數頁和列印設定頁以路由資料決定顯示哪些分組。
