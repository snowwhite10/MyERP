# ADR-049：稅率查詢拒絕停用稅別，以及物料、倉庫、儲位、稅別的引用契約

- 日期：2026-10-13
- 狀態：Accepted
- 工作單元：WU-MD-022b（第 2 段，代碼審查 MD-B04、MD-B05）

## 情境

1. ADR-038 第 5 點規定 `ITaxRateLookup.GetRatePercentAsync` 對停用稅別仍回稅率，由呼叫端自行判斷 `IsActive`。其他 Lookup（工序、付款條件、資金帳戶等）都以 `RequireActiveAsync` 拒絕停用資料；稅率是唯一要呼叫端記得檢查的契約，SD／PUR 開新單時漏查即可使用停用稅別（MD-B04）。
2. `CalculateAsync` 用 `GetPrecisionAsync` 取全部幣別的小數位；幣別代碼不在幣別主檔時默默使用預設 2 位小數，算出的金額與之後過帳的幣別精度可能不一致（MD-B04）。
3. 物料、倉庫、儲位、稅別／稅率沒有 `I*Usage` 契約。INV／SD／PUR 上線後，MD 無法阻止修改有庫存物料的基本單位、刪除有庫存的倉庫或儲位、回溯修改已有單據的稅率（MD-B05）。

## 決策

1. **稅率查詢預設拒絕停用稅別。** `GetRatePercentAsync`、`CalculateAsync` 加參數 `includeInactive = false`；預設對停用稅別回 422 `MD.TAX_CODE.INACTIVE`。重算歷史單據（例如退貨沿用原單稅別）時呼叫端明確傳 `includeInactive: true`。取代 ADR-038 第 5 點「停用稅別仍可查詢」的部分。
2. **稅率 API 維持可查停用稅別。** `GET /api/v1/md/tax-rates/lookup` 與 `POST /calculate` 是稅別維護頁的試算工具（`MD.TAX_CODE.VIEW`），使用者要能核對已停用稅別的歷史稅率，所以控制器傳 `includeInactive: true`，行為不變。
3. **試算幣別必須存在於幣別主檔。** `CalculateAsync` 以 `ICurrencyLookup.FindCurrencyAsync` 取該幣別；不存在回 404 `MD.CURRENCY.NOT_FOUND`（與 `GetRateAsync` 一致），存在時用其 `DecimalPlaces`（停用幣別仍可用，歷史單據）。只讀一筆幣別，不再載入全部幣別。格式錯誤仍為 400 `currencyCode`。
4. **新增四個引用契約**（`MyERP.Modules.MasterData.Contracts`，由使用方模組實作並註冊，MD 逐一詢問，不讀其他模組的表；沒有實作時視為未使用）：
   - `IItemUsage.IsInUseAsync(itemCode)`：有庫存、交易或單據引用此物料。物料改基本單位前檢查，使用中回 409 `MD.ITEM.BASE_UOM_LOCKED`（與「有專屬換算」同一錯誤碼）。物料目前沒有刪除功能；日後加入時同樣檢查。
   - `IWarehouseUsage.IsInUseAsync(warehouseCode)`：刪除倉庫前檢查，使用中回 409 `MD.WAREHOUSE.IN_USE`。
   - `IStorageLocationUsage.IsInUseAsync(warehouseCode, locationCode)`：刪除儲位前檢查，使用中回 409 `MD.STORAGE_LOCATION.IN_USE`。
   - `ITaxCodeUsage.IsInUseAsync(taxCode, from, to)`：有單據以此稅別且業務日期落在 `[from, to]`（`to` 為 null 表示不設上限）。刪除稅別檢查全期間；刪除稅率檢查該稅率期間；修改稅率時，稅率百分比改變則檢查原期間，只改期間則檢查原期間中不再被新期間涵蓋的部分。使用中回 409 `MD.TAX_CODE.IN_USE`／`MD.TAX_RATE.IN_USE`。新期間多涵蓋的日期原本沒有稅率（重疊檢查保證），不可能已有單據，所以不必檢查。
5. **匯率不設引用契約。** 單據保存自己的匯率（ADR-037），修改匯率不回溯，與付款條件（ADR-040）相同；MD-B05 提到的匯率不另設契約。
6. **跨模組並發。** MD 刪除時在自己的公司級鎖內詢問 Usage；使用方寫入引用時如何與 MD 刪除互斥（例如 INV 入庫與刪除儲位同時發生）由第一個使用方設計，與 MD-B06 批次契約一併處理（WU-MD-026）。

## 後果

- `ITaxRateLookup` 簽章改變（新增可選參數，原有呼叫端原始碼相容）；ADR-038 第 5 點對應文字以本 ADR 為準。
- 需求 REQ_F4118.38.5／38.6 改版；新增錯誤碼 `MD.TAX_CODE.INACTIVE`、`MD.WAREHOUSE.IN_USE`、`MD.STORAGE_LOCATION.IN_USE`、`MD.TAX_RATE.IN_USE` 的三語翻譯。
- 測試以假 Usage 實作驗證每個呼叫點（MD-USAGE-001～004）。
