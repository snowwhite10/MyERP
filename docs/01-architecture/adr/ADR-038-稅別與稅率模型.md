# ADR-038 — 稅別與稅率模型

- 日期：2026-10-12
- 狀態：Accepted
- 工作單元：WU-MD-017（稅率）

## 背景

BlueWhale 沒有獨立的稅率主檔（reference-notes 無對照）。舊系統只把稅率記成整數百分比：公司設定有「是否使用稅」與預設稅率，客戶與供應商各有預設稅率，銷售／採購明細行保存稅率、含稅單價、稅額與價稅合計，表頭另有「是否含稅」旗標。也就是說：稅率是百分比、在明細行計算稅額、含稅與否由單據決定。舊系統沒有稅率生效期間，稅率調整時只能逐一修改客戶、供應商資料。

MyERP 的 SD／PUR／FI 需要：按業務日期取得稅率（稅率調整不影響歷史單據）、分銷項與進項、以 decimal 與 `Money.Round` 在明細行計算稅額（MASTER_PROMPT 6.3）。`tax_` 前綴屬於 FI 的稅務交易（例如銷項／進項稅額明細、申報），本工作單元只做主檔。

## 決定

1. **兩張表：稅別 + 稅率期間。** 與 ADR-037 幣別／匯率相同的結構。
   - `md_tax_code`（REQ_DS43.119）：稅別主檔，沿用分類基底（代碼 1–30 位英數、`-`、`_`，公司內永久唯一；名稱 200；啟用；軟刪除；`custom_fields`），另加 `tax_type`（varchar(30)，`Output` 銷項／`Input` 進項／`Both` 兩者皆可）。代碼建立後不可修改；`tax_type` 可修改。
   - `md_tax_rate`（REQ_DS43.120）：稅率期間，`tax_code_id`、`effective_from`、可空 `effective_to`（含當日，空白表示持續有效）、`rate_percent`。
2. **稅率以百分比表示，`DECIMAL(7,4)`，0–100。** 例如 5% 存 `5.0000`、日本輕減稅率 8% 存 `8.0000`。百分比與舊系統、發票與使用者習慣一致；4 位小數足夠表示 `12.3456%` 一類特殊稅率。0 合法（零稅率、免稅以不同稅別代碼區分，例如 `ZERO`、`EXEMPT`，業務意義由稅別名稱與 FI 申報設定表達）。
3. **期間不重疊。** 同一稅別未刪除的稅率期間不可重疊（409 `MD.TAX_RATE.OVERLAP`），檢查條件與匯率相同，在公司級 applock `md_tax_code:{companyId}` 內檢查；資料庫另有 `(company_id, tax_code_id, effective_from) WHERE is_deleted = 0` 篩選唯一索引，以及 `rate_percent BETWEEN 0 AND 100`、`effective_to >= effective_from` CHECK。只能為啟用的稅別新增稅率（422 `MD.TAX_RATE.TAX_CODE_INACTIVE`）；既有稅率仍可修改、刪除。有稅率的稅別不可刪除（409 `MD.TAX_CODE.IN_USE`），只可停用。單據保存自己的稅率與稅額，修改或刪除稅率不回溯；稅率表不加 `is_active`。
4. **含稅／未稅由單據決定，不是稅別屬性。** 同一稅別可用於含稅報價與未稅報價（舊系統亦以表頭旗標決定）。計算規則放在共用核心 `MyERP.Shared.Monetary.Tax.Calculate(amount, ratePercent, priceIncludesTax, currency, precision)`，回傳 `TaxAmounts(Net, Tax, Gross)`：
   - 未稅：`Net = Round(amount)`，`Tax = Round(Net × rate ÷ 100)`，`Gross = Net + Tax`。
   - 含稅：`Gross = Round(amount)`，`Net = Round(Gross × 100 ÷ (100 + rate))`，`Tax = Gross − Net`（以差額求稅額，保證 `Net + Tax = Gross`，不會出現一分錢誤差）。
   - `Round` 為 `Money.Round(value, currency, precision)`，精度由呼叫端經 `ICurrencyLookup.GetPrecisionAsync` 取得；只在明細行計算，表頭稅額 = 明細稅額加總，不得以表頭合計重算。負數（退貨）對稱處理（AwayFromZero）。
   - 計算放在 Shared 而非 MD.Contracts，因為 Contracts 只放介面與 DTO（ArchitectureTests），而稅額計算是純函式、與 `Money` 同級。
5. **契約。** `MyERP.Modules.MasterData.Contracts.ITaxRateLookup`：
   - `FindTaxCodeAsync(code)`：含停用，不存在回 null；`TaxCodeInfo` 有 `AppliesToOutput`／`AppliesToInput`。
   - `GetRatePercentAsync(code, TaxDirection, date)`：稅別不存在 404 `MD.TAX_CODE.NOT_FOUND`；方向不符（例如以進項專用稅別開銷售單）422 `MD.TAX_RATE.DIRECTION_MISMATCH`；沒有涵蓋該日的稅率 422 `MD.TAX_RATE.NOT_FOUND`。停用稅別仍可查詢（歷史單據），新單據是否接受停用稅別由呼叫端以 `IsActive` 判斷。
   - `CalculateAsync(code, direction, date, amount, priceIncludesTax, currencyCode)`：取稅率後以 `ICurrencyLookup.GetPrecisionAsync` 的精度呼叫 `Tax.Calculate`，回傳 `TaxCalculation(RatePercent, Net, Tax, Gross)`。
6. **權限與 API。** `MD.TAX_CODE.VIEW／CREATE／EDIT／DELETE`。稅率屬於稅別主檔：查看需 VIEW，新增、修改、刪除需 EDIT（同 ADR-037）。API：`/api/v1/md/tax-codes`、`/api/v1/md/tax-codes/{taxCodeId}/rates`、`GET /api/v1/md/tax-rates/lookup?taxCode=&direction=&date=`、`POST /api/v1/md/tax-rates/calculate`（試算，前端顯示用）。
7. **不在本工作單元。** 客戶、供應商、物料的預設稅別欄位留待 SD／PUR 需要時，以 MD 追加欄位並經同一契約驗證；稅務申報、稅額明細（`tax_` 前綴）屬 FI。

## 影響

- 稅別與稅率是 BlueWhale 沒有的追加子功能（ADR-002）：REQ_F4118.37（Tax Code）、REQ_F4118.38（Tax Rate），介面追加 8.83–8.86。
- 示範資料（台灣 5% 營業稅、香港無增值稅）待 MD 種子資料建立時寫入（WU-MD-022 或 FI 種子）。
- SD／PUR／FI 取稅率一律經 `ITaxRateLookup`，不得讀 `md_tax_code`／`md_tax_rate`。
