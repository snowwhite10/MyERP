The following sources govern or inform this specification. The BlueWhale documents are confidential reference material stored outside version control; this SRS uses their chapter and table conventions without reproducing customer information.

- BlueWhaleERP_SRS.docx and BlueWhaleERP_SDS.docx, reference copies held in the project reference directory; chapter structure and formatting are summarized in the project reference notes.
- IEEE Std 830-1998, IEEE Recommended Practice for Software Requirements Specifications, cited as a document-organization reference in the BlueWhale baseline.
- MyERP MASTER_PROMPT.md, the project scope, technology and acceptance rules; and docs/00-management/project-charter.md, the project goals and boundaries.
- MyERP docs/00-management/reference-notes.md, the BlueWhale feature, interface and data-structure comparison; and docs/00-management/backlog.md and progress.md, the delivery plan and current status.
- MyERP docs/01-architecture/architecture.md and the architecture decision records, the system design constraints; and docs/02-modules/, the authoritative module requirements, data definitions, interface specifications and test plans.
