This Software Requirements Specification (SRS) defines the intended behavior and acceptance basis for MyERP, an enterprise resource planning system. It gives the product owner, developers, testers and reviewers a common description of the functions, data, interfaces and measurable quality requirements. A requirement described here is an acceptance target; its presence does not mean that the function has already been delivered.

The document uses the chapter structure and requirement-table format recorded from the BlueWhale ERP SRS in the project reference notes. MyERP requirements and designs are maintained in the module source files; the SRS, SDS and requirements workbook are generated from those sources. Requirement identifiers and the traceability workbook connect a function to its design, interface and tests.
