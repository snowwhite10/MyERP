MyERP is a browser-based, multi-company ERP for organizations that manage sales, purchasing, inventory, manufacturing and finance. The planned scope also includes master data, system administration, reporting and business intelligence, controlling, quality management, maintenance, customer relationship management, human resources, projects and supply chain management. Shared capabilities include authentication, permissions and data scope, audit history, document numbering, approvals, notifications, multiple currencies, three interface languages and light and dark themes.

The product is developed as an Angular client, an ASP.NET Core Web API and a SQL Server database, with Redis for supporting services. Modules own their business data and expose contracts to other modules. Financial postings must pass through the general ledger posting service, and inventory changes must pass through inventory-owned operations. Chapter 4 states the detailed functional, data, interface and non-functional requirements; the module backlog and progress record show the delivery status of each part.

The project deliverable is a locally runnable application and its generated SRS, SDS and requirements workbook. Production deployment, migration of a customer's legacy data, a native mobile application, and real customer or contract data are outside this project's committed scope. The BlueWhale feature comparison in the project reference notes identifies justified exclusions rather than silently dropping baseline features.
