Project responsibilities are assigned by deliverable so that a requirement can be reviewed even while the system is being developed incrementally. Personal names, client organizations and contract details remain placeholders until supplied by the project owner.

| Role | Responsibility |
|---|---|
| Project owner / sponsor | Maintains the governing project instructions, approves changes to them and resolves decisions that require human authority. |
| Infrastructure administrator | Provides the Windows environment, SQL Server, Redis, credentials and execution runner. |
| Project manager | Maintains the backlog, work-unit status, risks and delivery evidence. |
| Business analyst | Defines requirements, acceptance criteria and the BlueWhale baseline comparison. |
| Architect and developers | Maintain architecture decisions, module contracts, implementation and technical documentation. |
| Test engineer | Designs scenarios, executes automated and interface checks, and records failures and acceptance evidence. |
| Documentation maintainer | Generates the SRS, SDS and workbook and checks their consistency with sources and the database. |

In this project, the AI development agent performs the project management, analysis, architecture, development, testing and documentation roles under the governing instructions. Human responsibility for infrastructure and changes to those instructions remains with the project owner and administrator.
