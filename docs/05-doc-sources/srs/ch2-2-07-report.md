The Report module (BI) is planned to present purchasing, sales, production, inventory and financial reports, management dashboard indicators, comparisons, drill-down views and scheduled report outputs. REQ_F4117 groups these into seven sub-functions. Each report reads authorised, committed facts through the owning module's published query contract; BI owns the filters, grouping, display and export rather than changing business records.

Reports must identify the company, filters, units and source cutoff used for their figures. Detail, totals and exports of one report use the same frozen source set so that pagination or later writes do not silently change the result. A missing owner source is shown as unavailable, not as a zero balance. Financial reports require FI posted accounting sources; production reports require PP sources. Drill-down and scheduled downloads recheck the viewer's current permission and data scope.

The current BI work consists of requirements and design contracts. The existing home-page charts use demonstration values and are not accepted operational BI reports. Report endpoints, owner source integration, production data, scheduling, pages and real product verification remain future work.
