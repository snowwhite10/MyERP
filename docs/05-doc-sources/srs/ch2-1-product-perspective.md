MyERP is a browser-based enterprise resource planning system for multiple companies. A responsive Angular client communicates with an ASP.NET Core Web API over HTTPS. The API is a modular monolith backed by SQL Server 2022; Redis supports refresh tokens and shared cache. The delivered target is a locally runnable Windows environment. Production hosting and migration of customer data are outside the committed scope.

The system replaces separate spreadsheets and isolated business applications with controlled master data and traceable transactions. Each module owns its records and publishes application contracts or events for other modules. General ledger postings and inventory movements are accepted only through their owning services. Users select a company and receive only the functions and data permitted by their roles and data scope.

The interface provides Traditional Chinese, Simplified Chinese and English, with light and dark themes. Operational reports consume committed business data. The detailed behavior, interface items and measurable quality targets are specified in Chapter 4; actual delivery status is recorded separately in the project progress record.
