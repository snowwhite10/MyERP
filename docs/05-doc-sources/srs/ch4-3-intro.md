This section identifies the data structures required by the functional requirements. Each REQ_DS43 identifier is unique across MyERP and remains stable once allocated. The table name, purpose and related REQ_F identifiers are maintained in the owning module's data-structure source; the generated requirement tables below present their SRS descriptions.

Module ownership follows the table prefixes defined in the database conventions. A module may refer to another module's record by identifier but does not directly read or write that module's tables. The SDS database design obtains column definitions from the live SQL Server schema when a connection is supplied. Until that schema comparison runs successfully, the structures listed here are documented requirements, not evidence that every table or column exists in the database. The consistency report identifies missing links and any differences found during a live comparison.
