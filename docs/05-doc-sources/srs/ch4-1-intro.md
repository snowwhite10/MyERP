The functional requirements describe the behavior expected of the MyERP user portal and its business modules. Section 4.1.1 groups requirements by the fixed module and sub-function numbers; each requirement has a stable REQ_F411 identifier, a version, a description and an author. The maintained module requirements files also record acceptance criteria and changes to a requirement's version. An identifier remains assigned even when a function is deprecated.

The requirements cover the intended system scope, including functions that have not yet been implemented. Their presence in this SRS does not establish that an API, user interface or workflow has passed acceptance. The project backlog, test plans and progress record distinguish planned behavior from verified delivery. The requirements workbook links each functional requirement to applicable data structures, interface items and test cases; missing links are reported by the document consistency check.
