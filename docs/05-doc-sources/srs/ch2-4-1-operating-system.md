The current development and local acceptance path runs on Windows. Supported production operating systems are not yet qualified; deployment requires separate validation of the fixed technology stack and its dependencies.

| OS | Version and purpose |
|---|---|
| Windows | 64-bit Windows VM for local development and acceptance; runs SQL Server 2022, the ASP.NET Core API, Redis-compatible service and development tools. |
| Browser host | A current desktop or tablet operating system with a browser capable of running the Angular client; the browser support matrix remains subject to acceptance testing. |
