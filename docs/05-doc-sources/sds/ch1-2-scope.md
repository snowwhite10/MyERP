MyERP is a browser-based enterprise resource planning system for multi-company operations. Its planned scope includes system administration, master data, inventory, purchasing, sales, finance, controlling, reporting, production, quality, maintenance, customer relationships, human resources, projects and supply chain. Shared capabilities include authorization, workflow, document numbering, audit records, localization and accounting posting through the owning ledger service. The SRS and module requirements define the detailed functional boundaries.

This SDS covers the Angular client, ASP.NET Core Web API modular monolith, module contracts and data access, SQL Server 2022 database, Redis-compatible cache and development deployment on Windows. It also describes how database tables and interface designs are derived from authoritative sources. Production rollout, legacy data migration, native mobile applications and container deployment are outside the project scope defined in the charter.
