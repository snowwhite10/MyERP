The following terms and abbreviations are used in this SDS.

- ERP: Enterprise resource planning, the integrated business application described here.
- SRS: Software Requirements Specification, the source of required behavior and acceptance criteria.
- SDS: Software Design Specification, the design description linked to the SRS.
- API: Application programming interface, including the versioned HTTP endpoints and published module contracts.
- SPA: Single-page application, the Angular browser client.
- RBAC: Role-based access control, with permissions evaluated for the selected company and data scope.
- JWT: JSON Web Token, used for authenticated API requests.
- EF Core: Entity Framework Core, the backend object-relational mapper.
- ADR: Architecture Decision Record, a documented technical decision.
- GL: General ledger, the owner of posted accounting entries.
- Work unit: One bounded backlog increment with its own evidence, verification and status.

Identifiers beginning REQ_F, REQ_NF, REQ_DS and REQ_IO refer respectively to functional, non-functional, data-structure and interface requirements. The requirements workbook records their traceability to tests and design sources.
