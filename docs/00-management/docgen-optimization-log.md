## 2026-10-25T03:05:19+08:00 WU-P0-018

- 問題：`MyERP_SRS.docx` 正由 WINWORD 開啟，既有固定輸出路徑使文件產出在第一個檔案就失敗，無法檢查後續新增的需求來源。
- 原因：CLI 將來源根目錄與產出目錄綁在同一個 `RepositoryLayout` 固定位置。
- 修改：增加 `--output`，只替換產出目錄；相對路徑從 repo 根目錄計算，預設位置仍是 `docs/99-output`。文檔說明隔離執行法。
- 結果：先寫失敗路徑單元，實作後 DocGen 測試 8/8；實際 WINWORD 檔鎖期間，隔離目錄生成四個非空檔案。一致性檢查首次發現 11 個範圍式 ID 誤用，改為明列 ID 後 0 Error、608 Warning（無 SQL schema 的檢查）。
- 檢查：來源目錄仍基於 repo 根目錄；CLI 缺值或目標是檔案均顯示原因並非零退出。未動正式輸出、Word 程序或 SQL 設定。未加交易式四檔替換；產生失敗後隔離目錄可能有部分檔案，應以退出碼和報告判斷結果。
