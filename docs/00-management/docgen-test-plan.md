# DocGen CLI 驗收情境

## WU-P0-018：獨立輸出目錄

需求：正式產出路徑仍為 `docs/99-output`；當該目錄中的文件被使用者開啟時，操作者可用 `--output` 指定另一個目錄，建立完整 SRS、SDS、試算表及一致性報告。產出仍只讀取原 repo 來源，並依相同一致性規則傳回退出碼。此工具沒有業務 `REQ_F`；對應 MASTER_PROMPT 15.8。

| 測試案例 ID | 類別 | 層級 | 情境與驗收條件 | 狀態 |
|---|---|---|---|---|
| DOCGEN-OUT-001 | 正常 | U + CLI | 預設輸出仍為 repo `docs/99-output`；指定外部絕對路徑時四項產出均落於指定目錄，來源仍從 repo 讀取。 | PASS：路徑單元與四產物 CLI |
| DOCGEN-OUT-002 | 邊界 | U + CLI | 含空白的目錄可用；相對路徑以 repo 根目錄解釋；`--output` 缺值回使用錯誤碼。 | PASS：路徑單元、缺值 CLI；含空白實際 CLI 未跑 |
| DOCGEN-OUT-003 | 重複與衝突 | CLI | 正式 SRS 被 Word 佔用時，指定隔離目錄仍成功；隔離目錄再次執行可更新，正式產出不受影響。 | PASS：WINWORD 正佔用時隔離產出兩次 |
| DOCGEN-OUT-004 | 部分結果 | CLI | 無法建立輸出目錄或檔案時回非零碼，不宣稱成功。批次逐列略過不適用，因為 CLI 只建立一組文件；產生中若失敗，已寫檔可能留下，下一次可重建。 | PASS：目標為檔案時非零退出 |
| DOCGEN-OUT-005 | 權限 | CLI | 跨公司／資料範圍不適用，因為文件產生器不是登入 API。檔案系統無寫入權限由既有 `UnauthorizedAccessException` 處理。 | 未實測 ACL 拒絕 |

| DOCGEN-OUT-009 | 檔案 | CLI | 產生四個非空文件；空檔、格式錯誤、編碼與欄位缺失由既有來源解析及一致性檢查處理，這輪不改該規則。 | PASS：四產物非空、0 Error；未逐份以 Office 開啟 |

|---|---|---|---|---|

| DOCGEN-DIAG-002 | 邊界 | U | 空 Mermaid 區塊報來源行號；PNG 須有有效標頭與非零尺寸，過大圖按頁面寬高等比例縮小。 | 空圖 PASS；PNG 驗證／縮放由實作檢查，未另寫鏡像測試 |

| DOCGEN-DIAG-005 | 權限 | CLI | 無登入權限或跨公司情境不適用；本機需有來源讀取與隔離目錄寫入權限。 | 不適用業務權限 |
| DOCGEN-DIAG-006 | 狀態 | CLI | 草稿／審批／過帳不適用；正式甘特圖在日期未核准前保持待辦，依賴圖不得暗示日期。 | PASS：來源文字核對 |
