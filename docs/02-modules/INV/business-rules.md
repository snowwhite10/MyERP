# INV 業務規則

## 物料期初庫存（WU-INV-007a，ADR-059）

- BR-INV-018：期初是設定作業，不經 SYS 審批；提交即以 `OPENING_STOCK` 入庫，單價保存為入庫成本快照。批次不可修改或刪除，錯誤以其他入庫／出庫更正，保留審計軌跡。舊系統允許直接刪改期初數量，MyERP 不沿用。
- BR-INV-019：同公司每個物料＋倉庫＋儲位（無儲位視為一個鍵）只有一筆期初；啟用日期不可晚於今天，亦不可晚於該鍵已存在的最早異動日期。並發的其他入庫不取結存鍵鎖，若在檢查後才提交，以盤點校正。
- BR-INV-020：提交在公司級 `inv_opening_stock` 排他鎖內處理：先比對 `requestKey`，相同內容回原批次，不同內容回 409；再重新驗證全部行（MD 共享鎖持有至提交），任一行有錯則整批 422，不留下批次、引用或異動。預覽使用相同規則但不寫資料。

- BR-INV-017：庫存查詢只讀異動帳；零結存不列於結存列表，無異動仍可由內部 `GetOnHandAsync` 回零。公司隔離由 DbContext global query filter 保護，HTTP 端點另以 VIEW 權限保護；代碼採過帳時引用快照，MD 名稱由前端透過 MD API 載入。

- BR-INV-001：每筆庫存交易由目前公司隔離，跨公司單據狀態轉換立即拒絕；`inv_reference` 已套用公司篩選，跨模組不建 SQL 外鍵。
- BR-INV-002：數量用基本單位 `decimal(19,6)`；出庫不得造成負庫存；異動帳不可改寫，來源行防重放。
- BR-INV-003：單據狀態依 ADR-051；核准後才能過帳，已過帳以反向單據沖回。
- BR-INV-004：有儲位管理的倉庫要求同公司、同倉庫且啟用的儲位；否則儲位為 null。
- BR-INV-005：引用物料與倉庫時，先取得公司級 `md_item`、`md_warehouse` 共享鎖，再驗證同公司、未刪除且啟用；儲位須屬所選倉庫。鎖持有到寫入交易提交，與 MD 物料／倉庫／儲位刪除排他鎖互斥。使用中檢查須在排他鎖內執行。
- BR-INV-006：INV 來源行以公司與 `source_key` 唯一識別，首次寫入持久化引用 ID 與不可變代碼快照。已被引用的主檔只能停用，不可刪除；歷史引用不因來源作廢而移除。後續庫存寫入方必須先呼叫 `InventoryReferenceService.RecordAsync`，同一交易內寫來源與引用。
- BR-INV-007：來源類型與 ID 在公司內只允許一份異動內容。再次提交相同日期與完整明細回原異動 ID；任何差異回衝突。來源鎖、MD 引用鎖、結存鍵鎖依固定順序取得，持有至交易提交。
- BR-INV-008：同一結存鍵的出庫先取排他鎖，再以已提交異動合計加本次淨額檢查非負；交易失敗時新增引用與異動一起回滾。純入庫只增加結存，無須競爭出庫鍵鎖。
- BR-INV-009：`inv_stock_movement` 的 UPDATE／DELETE 由 SQL trigger 拒絕。現存量即時由方向與正數數量加總；來源單據沖回以新的反向過帳表示。物料基本單位換算由上游單據負責，本服務拒絕超過六位小數的數量。

具體事務與估值規則見 ADR-051；舊系統原始碼只作業務規則參考，不沿用其表結構或程式碼。

## 其他入庫（WU-INV-004a 已實作）

- BR-INV-010：其他入庫單號由 SYS `INumberGenerator` 按 `INV.OTHER_RECEIPT` 在建立交易內產生；單據及所有明細以同公司篩選，跨公司主檔由 MD guard 驗證。草稿建立／整組替換明細時不寫庫存異動。
- BR-INV-011：至少一行、行號不重複、數量為基本單位正數且最多六位小數；入庫單價為非負且最多六位小數。明細金額 = `quantity × unitCost` 在明細行取 4 位小數（遠離零）保存，表頭金額為明細加總且須小於 10^15，用於 SYS 審批門檻與列表顯示；成本估值法仍由 WU-INV-014 處理（ADR-055）。
- BR-INV-012：草稿可修改或軟刪除；送審後凍結。SYS 駁回後保留歷史，須先修訂（回草稿）才可再送審或刪除。SYS 最終核准及 `OTHER_RECEIPT` 異動帳過帳必須共用交易；任一步失敗全數回滾。已過帳不可修改或刪除，只能以新單據反向沖回。
- BR-INV-013：SYS 審批人與提交人不能由單據端點直接寫核准狀態；審批處理器依最近審批實例與目前公司核對。重送相同核准不增加異動帳，已過帳內容不能變動。列印／匯出讀取已保存快照。

## 其他出庫（WU-INV-005a）

- BR-INV-014：`INV.OTHER_ISSUE` 單號與草稿在同一交易建立；草稿只驗證同公司主檔及正數六位基本單位數量，不預扣庫存。駁回後先修訂回草稿才可重送。
- BR-INV-015：單價及金額是審批門檻估算，按明細行取四位小數；過帳的 `StockDirection.Out` 成本為 null，由 WU-INV-014 估值，不允許以估算單價改寫異動成本。
- BR-INV-016：SYS 最終核准、單據已過帳狀態與 `OTHER_ISSUE` 異動須同交易。過帳服務在公司、物料、倉庫、儲位結存鍵持排他鎖並檢查非負；不足時 SYS 決定與單據狀態一起回滾。已過帳不可編輯或刪除。
