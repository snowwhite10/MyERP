# INV 業務規則

## WU-INV-012d 拆卸入庫（ADR-069；待實作）

- BR-INV-058：拆卸屬 INV，手動保存一個成品來源行與 1–999 個組件目的行，不要求 PP BOM。成品物料不可同時作組件；各組件正數六位成本分攤權重為相對值，依保存行號排序分攤，不由前端指定實際入庫單價。
- BR-INV-059：草稿不預扣庫存，MD 引用以 Contracts guard 驗同公司、啟用及儲位所屬；草稿批序號可暫缺，送審須符合追蹤方式與行數量。成品批序號自來源位置耗用，組件批序號於目的位置入庫；同單序號不得重複產出或同時作來源與產出。
- BR-INV-060：`INV.DISASSEMBLY` 由 SYS 審批，金額 0。最終核准按物料 ID 升序取得公司／物料交易鎖，鎖定成品可靠移動平均；成品行值為數量乘平均成本四位捨入。前 N−1 個組件按權重占比分得四位行值，末行取總值扣已分配值；各行六位入庫單價必須四位重算等於分得值，否則 `COST_PRECISION` 全單拒絕；未知／未定價回 `COST_UNKNOWN`，溢位回 `COST_OVERFLOW`，明確零成本可過帳。出庫異動單價為 null，鎖定單價記於單據行，組件入庫單價記於單據行及異動帳。
- BR-INV-061：SYS 最終決定、成品 Out、組件 In 及 Posted 同交易；來源 `DISASSEMBLY` 加單據 ID 防重放。成品結存或批號不足、序號衝突、MD 引用失效與任一寫入失敗均回滾整單；不允許部分成功或略過。相同來源快照重放不增加異動，變更快照 409；雙連線爭同一來源不能超賣。
- BR-INV-062：草稿可按版本整組修訂／軟刪；駁回保留意見與歷史，修訂後回草稿。待審或已過帳不可修改／刪除；已過帳更正須另開單據，不能改原異動。查詢與已保存停用引用顯示經 MD／SYS Application 契約，不讀其資料表。

## 安全庫存（WU-INV-013d，ADR-067）

- BR-INV-052：每公司、物料、倉庫永久只有一筆門檻；六位基本單位數量須大於零。刪除為軟刪，重設同鍵恢復原記錄並保留版本／審計歷史；寫入經 MD Contracts 與引用鎖檢查目前公司和啟用狀態。
- BR-INV-053：警示現存量為該倉庫全部儲位的已過帳異動 `In - Out`，未設定門檻不警示。零結存仍參與比較；只有 `onHand < minimumQuantity` 才為低量，相等不警示，建議補足為正差額，非低量為零。批序號明細不另加一次。
- BR-INV-054：低量查詢純讀，按目前公司先計算篩選與總筆數再分頁；不建立採購單、不預扣或更改異動帳。顯示查詢時間與提示性質；已停用的歷史 MD 引用仍可讀，新增或編輯門檻時不可使用停用引用。

## 組裝入庫（WU-INV-011d；ADR-066）

- BR-INV-047：組裝單屬 INV；一個成品行及至少一個耗料行構成一次組裝。PP BOM 僅是未來可選建議，INV 不查 PP 表，展開後的行由 INV 保存快照；目前可完全手動建立。成品物料不能同時作耗料，以免同物料成本池在一次操作內自我循環。
- BR-INV-048：草稿不預扣庫存；耗料物料、倉庫、儲位及成品目的倉儲都須通過 MD guard。數量用六位基本單位，耗料批序號必須在來源結存鍵可用；成品批序號按入庫規則建立或復用。草稿可暫缺批序號，送審前必須完整。
- BR-INV-049：送審經 SYS `INV.ASSEMBLY` 文件類型，審批金額為 0。最終核准、耗料 Out、成品 In 與 Posted 在同一交易；每個保存行只有一個方向，來源 `ASSEMBLY` 加單據 ID 防重放。任何耗料不足、序號衝突或 MD 引用失效均回滾全部，不允許部分組裝。
- BR-INV-050：成品價值等於核准時耗料按 INV 已鎖定估值快照計算的總出庫價值；成品單價依總值與成品數量計算，不由前端傳入。若任一耗料成本未知或運算溢位，拒絕核准，不能把未知值當零；四位行金額尾差及六位單價精度由後端成本契約測試固定。
- BR-INV-050a：INV 每次新過帳在引用與結存檢查前，按物料 ID 升序取得公司／物料交易排他鎖；組裝成本快照在呼叫端交易取得相同鎖後才查估值。鎖持有至交易提交或回滾，避免計價快照與並發入庫／出庫交錯。來源重放若不產生異動，無需估值鎖。
- BR-INV-050b：組裝最終核准先按 ID 鎖定成品及全部耗料物料，再查耗料當前移動平均。每個耗料行按 `Round(quantity × averageUnitCost, 4, AwayFromZero)` 計值，成品單價按總值除成品數量取六位；該單價乘成品數量再取四位必須等於耗料行值總和，否則以 `COST_PRECISION` 拒絕，不以無法保存的尾差虛構成本。未知或有未定價數量回 `COST_UNKNOWN`，運算溢位回 `COST_OVERFLOW`。核准時的耗料單價存於組裝行，異動帳出庫單價保持 null 以符合既有估值規則。
- BR-INV-051：草稿可按版本整組修改或軟刪；駁回保留審批歷史且先修訂回草稿；待審、已過帳不可改或刪。相同核准再送由 SYS 拒絕，過帳來源快照相同重放不增異動、不同內容 409。已過帳更正須新單據，不改原異動。

## PUR／SD 來源過帳（WU-INV-015d；ADR-064）

- BR-INV-040：PUR 與 SD 擁有來源單據及其審批權限；INV 只接受來源 Application 處理器在 SYS 最終核准交易內送出的已保存內容。固定來源類型分別為 `PURCHASE_INBOUND`／`SALES_OUTBOUND`，方向分別全 In／全 Out；不得由 HTTP 用戶端直接提交過帳指令。
- BR-INV-041：PUR 入庫保存基本單位數量、成本快照及批序號；SD 出庫保存基本單位數量及批序號，過帳成本為 null。來源處理器在目前公司重新讀取待審單據與版本，與 SYS 決定、單據 Posted 狀態及 INV 異動共用交易。任何錯誤回滾全部；駁回不寫異動。
- BR-INV-042：同公司同來源類型及 ID 的快照相同才允許重放；不同內容回 `INV.POSTING.CONFLICT`。來源已 Posted 時仍由來源模組拒絕再次核准；反向沖回另建來源單據。跨公司 ID 相同不互相重放，並發來源及結存鍵沿用 BR-INV-007／008 的鎖。

## 庫存估值（WU-INV-014d，ADR-063）

- BR-INV-036：按公司＋物料彙成一個移動加權平均成本池，依 `posted_at, id` 處理已提交異動，截止值也使用過帳時間；業務日期不重新排列歷史成本。結果為暫估。
- BR-INV-037：已知成本入庫的行值、出庫的平均成本行值各取四位小數（遠離零）；數量六位。出庫使池量歸零時取走剩餘全部價值。零成本是已知成本，不能與 NULL 混用。
- BR-INV-038：同來源 `TRANSFER` 出入兩腿在公司＋物料池數量及金額中性；批序號、倉庫及儲位不獨立計價。無成本盤盈／入庫沿用入庫前平均，當沒有已知池值時標記 `Unpriced`，金額為 NULL，直到未定價池歸零後由已知入庫重新開始。
- BR-INV-039：估值只讀不可變異動帳；負池量、調撥不配對或數值溢位報錯。FI 僅經 INV 唯讀契約取得暫估資料，月結要另行封存與過帳，不能直接以此查詢寫總帳。

## 盤點（WU-INV-010，ADR-062）

- BR-INV-031：盤點範圍是 1–20 個倉庫，加上可選的物料類別（含下層）與物料。快照只讀異動帳，取結存大於 0 的「物料＋倉庫＋儲位」鍵，批序號物料再細分到號碼，同時保存快照時間與最大異動 ID。建立不寫異動，也不凍結倉庫。舊系統的帳面數量來自瀏覽器、沒有快照，MyERP 不沿用。
- BR-INV-032：同公司同一「物料＋倉庫」只能在一張未結盤點單（草稿、待審、已核准、駁回）。在公司級盤點鎖內檢查，軟刪除或過帳後才釋放。
- BR-INV-033：送審時，範圍內現存量（含批序號）必須與快照完全相同，而且快照後沒有範圍內的新異動；否則回 `INV.STOCKTAKE.SNAPSHOT_STALE`。系統不自動改差異，由使用者重新快照：更新帳面、保留實盤、帳面有變的行標記重盤。送審後才發生的異動視為點數以後的業務，與核准的差異疊加。
- BR-INV-034：差異 = 實盤 − 帳面。最終 SYS 核准、Posted 與盈虧異動在同一交易：每行批序號的正差異合計入庫、負差異合計出庫，同一行號最多一入一出，成本空；差異為 0 不寫異動。盤虧令結存為負，或批號／序號不在該位置時，全部回滾。盤盈序號須符合全公司結存 ≤ 1。一張盤點的盈虧最多 1,000 筆異動、10,000 個批序號差異（過帳服務上限），送審時超過即回 `INV.STOCKTAKE.TOO_MANY_LINES`，要求縮小範圍。
- BR-INV-035：送審時每行、每個批序號都必須有實盤值（可為 0）；新增的實地行，帳面為 0，倉庫須在範圍內。草稿與駁回修訂整組保存並檢查版本；只有草稿可軟刪除；待審及已過帳不可修改。審批金額為 0；盈虧報表只顯示數量，金額待 WU-INV-014 估值。

## 庫存調撥（WU-INV-009，ADR-061）

- BR-INV-026：一行調撥定義物料、來源結存鍵、目的結存鍵與數量；兩個結存鍵不得相同（NULL 儲位視為同一鍵），允許同倉不同儲位。來源和目的均在目前公司，啟用物料、倉庫、儲位須經 MD guard 驗證，儲位須屬指定倉庫。
- BR-INV-027：草稿不預扣庫存，最終 SYS 核准在同一交易對每行產生一筆來源 `Out` 和一筆目的 `In`，兩筆物料、數量、行號和批序號相同；全部明細的總入庫數量必等於總出庫數量。出庫成本與入庫成本均空，價值轉移留估值單元；過帳來源 `TRANSFER` + 單據 ID 防重放。
- BR-INV-028：來源結存不足、來源批號不足、序號不在來源位置、MD 在送審後停用或任一過帳寫入失敗，SYS 決定、單據狀態及所有出入異動全部回滾。同一來源結存鍵按既有排他鎖序列化，兩個並發調撥不可超賣。
- BR-INV-029：批號或序號清單從來源原樣搬到目的，不能改號碼、拆少或多入。調撥草稿可暫缺，送審須符合追蹤方式並加總等於行數量。同物料序號在整張單據只能使用一次；同來源兩方向各一次是合法配對。轉倉後追溯應只在目的結存鍵呈現正數。
- BR-INV-030：草稿可編輯、軟刪；駁回單須先修訂回草稿才能再送審；待審與已過帳明細不可改。審批金額為 0，由 `INV.TRANSFER` 文件類型工作流控制，調撥本身不產生收入或費用。

## 批號與序號（WU-INV-008b，ADR-060）

- BR-INV-021：追蹤方式屬 MD 物料主檔（`None`／`Lot`／`Serial`），由過帳服務在 MD 共享鎖內讀取。`None` 物料不可帶批序號；`Lot` 物料只帶批號、`Serial` 物料只帶序號且數量為整數；合計必須等於明細數量。單據草稿可暫缺，送審、核准或期初提交時必須完整。
- BR-INV-022：批號與序號以「公司 + 物料 + 號碼」識別，去除前後空白後不分大小寫比較；不同物料可有相同號碼。批號首次入庫建立並保存可選生產日期與有效期限；後續入庫省略日期則沿用，提供不同日期即拒絕，避免同一批號有兩組屬性。
- BR-INV-023：批號與序號不存數量或狀態欄；結存只由 `inv_stock_movement_tracking`（只增不改）依異動方向即時加總，按異動的倉庫／儲位分組。舊系統沒有批序號，MyERP 為擴充功能。
- BR-INV-024：出庫時在已取得的結存鍵排他鎖內，逐一以「既有批序號結存 + 本次淨額 ≥ 0」核對同一倉庫＋儲位；同一來源的調撥（出後入）以淨額計算。序號入庫要求全公司結存 + 本次淨額 ≤ 1；有批序號入庫的物料取 `inv_tracking:{公司}:{物料}` 排他鎖（排在結存鍵鎖之後、按物料排序），序列化批號建立與序號重複入庫檢查。
- BR-INV-025：單據批序號保存在明細子表（非 JSON），保留輸入順序；核准或提交時原樣轉為過帳批序號。冪等重放比較每行批序號（號碼不分大小寫、數量），日期屬批號屬性不列入比較。期初重送比較包含批序號與日期。

## 物料期初庫存（WU-INV-007a，ADR-059）

- BR-INV-018：期初是設定作業，不經 SYS 審批；提交即以 `OPENING_STOCK` 入庫，單價保存為入庫成本快照。批次不可修改或刪除，錯誤以其他入庫／出庫更正，保留審計軌跡。舊系統允許直接刪改期初數量，MyERP 不沿用。
- BR-INV-019：同公司每個物料＋倉庫＋儲位（無儲位視為一個鍵）只有一筆期初；啟用日期不可晚於今天，亦不可晚於該鍵已存在的最早異動日期。並發的其他入庫不取結存鍵鎖，若在檢查後才提交，以盤點校正。
- BR-INV-020：提交在公司級 `inv_opening_stock` 排他鎖內處理：先比對 `requestKey`，相同內容回原批次，不同內容回 409；再重新驗證全部行（MD 共享鎖持有至提交），任一行有錯則整批 422，不留下批次、引用或異動。預覽使用相同規則但不寫資料。

- BR-INV-017：庫存查詢只讀異動帳；零結存不列於結存列表，無異動仍可由內部 `GetOnHandAsync` 回零。公司隔離由 DbContext global query filter 保護，HTTP 端點另以 VIEW 權限保護；代碼採過帳時引用快照，MD 名稱由前端透過 MD API 載入。

- BR-INV-001：每筆庫存交易由目前公司隔離，跨公司單據狀態轉換立即拒絕；`inv_reference` 已套用公司篩選，跨模組不建 SQL 外鍵。
- BR-INV-002：數量用基本單位 `decimal(19,6)`；出庫不得造成負庫存；異動帳不可改寫，來源行防重放。
- BR-INV-003：單據狀態依 ADR-051；核准後才能過帳，已過帳以反向單據沖回。
- BR-INV-004：有儲位管理的倉庫要求同公司、同倉庫且啟用的儲位；否則儲位為 null。
- BR-INV-005：引用物料與倉庫時，先取得公司級 `md_item`、`md_warehouse` 共享鎖，再驗證同公司、未刪除且啟用；儲位須屬所選倉庫。鎖持有到寫入交易提交，與 MD 物料／倉庫／儲位刪除排他鎖互斥。使用中檢查須在排他鎖內執行。
- BR-INV-006：INV 來源行以公司與 `source_key` 唯一識別，首次寫入持久化引用 ID 與不可變代碼快照。已被引用的主檔只能停用，不可刪除；歷史引用不因來源作廢而移除。後續庫存寫入方必須先呼叫 `InventoryReferenceService.RecordAsync`，同一交易內寫來源與引用。
- BR-INV-007：來源類型與 ID 在公司內只允許一份異動內容。再次提交相同日期與完整明細回原異動 ID；任何差異回衝突。來源鎖、MD 引用鎖、結存鍵鎖依固定順序取得，持有至交易提交。
- BR-INV-008：同一結存鍵的出庫先取排他鎖，再以已提交異動合計加本次淨額檢查非負；交易失敗時新增引用與異動一起回滾。純入庫只增加結存，無須競爭出庫鍵鎖。
- BR-INV-009：`inv_stock_movement` 的 UPDATE／DELETE 由 SQL trigger 拒絕。現存量即時由方向與正數數量加總；來源單據沖回以新的反向過帳表示。物料基本單位換算由上游單據負責，本服務拒絕超過六位小數的數量。

具體事務與估值規則見 ADR-051；舊系統原始碼只作業務規則參考，不沿用其表結構或程式碼。

## 其他入庫（WU-INV-004a 已實作）

- BR-INV-010：其他入庫單號由 SYS `INumberGenerator` 按 `INV.OTHER_RECEIPT` 在建立交易內產生；單據及所有明細以同公司篩選，跨公司主檔由 MD guard 驗證。草稿建立／整組替換明細時不寫庫存異動。
- BR-INV-011：至少一行、行號不重複、數量為基本單位正數且最多六位小數；入庫單價為非負且最多六位小數。明細金額 = `quantity × unitCost` 在明細行取 4 位小數（遠離零）保存，表頭金額為明細加總且須小於 10^15，用於 SYS 審批門檻與列表顯示；成本估值法仍由 WU-INV-014 處理（ADR-055）。
- BR-INV-012：草稿可修改或軟刪除；送審後凍結。SYS 駁回後保留歷史，須先修訂（回草稿）才可再送審或刪除。SYS 最終核准及 `OTHER_RECEIPT` 異動帳過帳必須共用交易；任一步失敗全數回滾。已過帳不可修改或刪除，只能以新單據反向沖回。
- BR-INV-013：SYS 審批人與提交人不能由單據端點直接寫核准狀態；審批處理器依最近審批實例與目前公司核對。重送相同核准不增加異動帳，已過帳內容不能變動。列印／匯出讀取已保存快照。

## 其他出庫（WU-INV-005a）

- BR-INV-014：`INV.OTHER_ISSUE` 單號與草稿在同一交易建立；草稿只驗證同公司主檔及正數六位基本單位數量，不預扣庫存。駁回後先修訂回草稿才可重送。
- BR-INV-015：單價及金額是審批門檻估算，按明細行取四位小數；過帳的 `StockDirection.Out` 成本為 null，由 WU-INV-014 估值，不允許以估算單價改寫異動成本。
- BR-INV-016：SYS 最終核准、單據已過帳狀態與 `OTHER_ISSUE` 異動須同交易。過帳服務在公司、物料、倉庫、儲位結存鍵持排他鎖並檢查非負；不足時 SYS 決定與單據狀態一起回滾。已過帳不可編輯或刪除。
# 共用選擇資料（WU-INV-016d，ADR-065）

- BR-INV-043：INV 選擇資料只讀 MD Contracts，不建立主檔副本，也不直接查寫 MD 表。選項回 ID、代碼與名稱；物料額外回傳追蹤方式，供表單在沒有 MD 主檔 VIEW 權限及全量預載時檢查批序號，倉庫／儲位此欄為 null。選項按目前公司及啟用／未刪除篩選；主檔所有權仍在 MD。
- BR-INV-044：選項查詢授權須是 INV 單據 CREATE 或 EDIT 之一，毋須 MD 主檔 VIEW；INV 純查看權不可因此列出可用主檔。儲位查詢必須帶啟用的目前公司倉庫，跨公司父倉庫不洩漏內容。
- BR-INV-045：確認選項只改前端草稿；換倉庫立即清空舊儲位，取消不改草稿。編輯已保存而現已停用的引用時顯示原值，禁止再選，但最終提交由既有 MD guard 在交易中驗證，避免選項查詢與保存間的競態。
- 盤點範圍的物料及倉庫以共用分頁框多選，實地新增行用單選；倉庫必須屬於已保存盤點範圍。盤點類別仍由 MD API 提供，僅有 `MD.ITEM_CATEGORY.VIEW` 才載入；沒有此權限時顯示說明，使用者可只按倉庫或物料建立盤點。已存盤點行以單據受權引用端點顯示停用名稱，保存時仍由 MD guard 驗證。
- BR-INV-046：已保存引用的顯示查詢只可由已授權且屬目前公司的單據詳情衍生主檔 ID；MD Contracts 可回傳未刪除的停用物料／倉庫／儲位及 `isActive`，不得開放任意 ID 查詢或併入只列啟用資料的新增選項。盤點範圍內已保存的物料與倉庫亦屬可顯示引用。
# 庫存報表與大量匯出（WU-INV-017d，ADR-068）

- BR-INV-055：進出存期初為 `business_date < from` 的入減出；期間入、出分別加總含頭尾日期的異動，期末為期初＋入－出。依公司／物料／倉庫／儲位分組，數量六位精度；負數照實顯示並標異常。只讀已提交的過帳異動，不讀草稿、審批中或 MD 庫存欄位。
- BR-INV-056：每次報表及完整匯出以單一資料庫一致性快照取數；跨 HTTP 查詢需重跑並更新查詢時間。匯出採伺服器串流 UTF-8 BOM CSV，逐欄防公式注入；超列數上限時拒絕整份請求並告知篩選，取消時停止讀取，不產生宣稱完整的截斷檔。數量報表不推導金額，估值遵照 ADR-063。
- BR-INV-057：批序號完整歷史匯出須具有追溯查看及匯出權限，只讀當前公司且不能沿用詳情的最近 1000 筆限制。所有列按過帳時間及異動 ID 穩定排序；若超匯出上限明確回 422。不可把跨公司或無權限的資料以空報表掩蓋。
