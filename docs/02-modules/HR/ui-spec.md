# HR — Planned interfaces

Proposed interfaces: Employee View/Create/Edit/Transfer/Terminate; Workforce Structure View/Assign; Roster View/Create/Publish; Attendance View/Correct/Approve; Payroll Run View/Calculate/Approve/Release/Reversal/Results; Leave View/Request/Approve/Balance; Vacancy View/Create/Approve; Candidate View/Apply/Convert; Performance Review View/Create/Approve; Training Session View/Create/Enrol/Completion. WU-HR-000d delivers no screen and allocates no `REQ_IO_A14`.

Screens must support three languages and light/dark mode. Sensitive identity, pay, bank and review fields are masked by default and scoped separately; self-service never shows colleagues' data. Payroll preview distinguishes calculated, approved, released, payment delivered and FI confirmed states. Leave balance declares as-of date and pending requests separately. Roster and attendance display timezone and overnight shift. Batch training/payroll actions show changed/skipped/failed/pending counts and row reasons; zero change uses warning. Disabled actions explain status, rights or unavailable SYS/FI owner. Normal, empty, denied, validation, server failure, partial and success states must match persisted outcomes. Exports freeze source membership and recheck permission at download.
